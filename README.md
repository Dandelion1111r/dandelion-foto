# dandelion-foto

Dandelion 11:11 Fotografie – Website unter https://foto.dandelion1111.de

## Neue Fotos hinzufügen

1. Foto (am besten als `.webp` oder `.jpg`, max. ca. 1500 px breit) in den Ordner `galerie/` hochladen.
2. In `index.html` im Bereich `<div class="gallery">` eine `<figure>`-Zeile kopieren und Dateiname, Beschreibung (`alt`) und Bildunterschrift anpassen.
3. Kategorie über `data-cat` wählen: `produkte`, `momente` oder `hochzeit`.
